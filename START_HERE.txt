Проверка сайта «Жесты» на Windows

1. Распакуйте ZIP целиком в отдельную папку.
2. Дважды щёлкните START_WINDOWS.cmd. Нужен установленный Python 3.
3. Когда появится строка «Serving HTTP», откройте http://localhost:8765/ в Chrome или Edge.
4. Разрешите доступ к камере. Держите окно с сервером открытым во время проверки.
5. Чтобы остановить сайт, закройте окно сервера.

Важно: index.html нельзя открывать двойным щелчком как файл. Адрес localhost
работает только на том компьютере, где запущен сервер. Для первой загрузки
TensorFlow.js и MediaPipe нужен интернет.

Если Python 3 не установлен, попросите отправителя опубликовать сайт по HTTPS
и прислать ссылку. При ошибке сообщите ему букву, надпись «Распознано»,
подсказку и по возможности приложите снимок экрана.
