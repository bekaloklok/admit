# Жесты — тренажёр русского дактиля

В справочнике доступны все 33 буквы. Камера находит 21 точку руки через MediaPipe, нормализует их и передаёт модели из `alphabet-model.json` и `alphabet-weights.bin`. Для А, Д, И/Й, К и формы Ш/Щ дополнительно работают модели `a-invariant-*`, `d-invariant-*`, `i-invariant-*`, `k-invariant-*` и `sh-invariant-*`: они сравнивают расстояния между точками, поэтому переносят поворот и зеркальное отражение руки. Модели обучены на координатах [RSL-Dataset](https://github.com/Blockbattle/RSL-Dataset). Интерфейс написан на React, Tailwind CSS и shadcn/ui.

## Что работает

- Модель определяет 31 различимую по форме группу букв. Для Ш/Щ и Ъ/Ь датасет использует общие классы: эти пары различаются движением. Для Ё в датасете есть два варианта формы.
- Урок охватывает 33 буквы; любую можно выбрать в справочнике и тренировать отдельно.
- Для Д, Ё, Й, К, Щ, Ъ и Ь камера сначала фиксирует форму, затем следит за движением даже при краткой ошибке классификации во время жеста. Для Д проверяется круг кончиками указательного и среднего пальцев, для Й — форма И и поворот кисти, для К — форма с двумя выпрямленными пальцами и короткое движение кисти вниз, для Ё — поворот кисти туда и обратно, для Щ — движение кисти вниз, для Ъ/Ь — наклон кисти в разные стороны по глубине кадра. Одно фото не засчитывает эти буквы.
- Все 33 подсказки написаны вручную по учебным описаниям жестов. Прежние советы «согни/выпрями такой-то палец» по углам 2D-точек удалены: при повороте руки они могли называть не тот палец. Для И и Й теперь указаны поднятые безымянный и мизинец; подсказка для Б описывает согнутую верхнюю фалангу среднего пальца. Оценка основной модели на экране не считается гарантированной вероятностью.
- «Проверить образец» использует координаты из датасета. Для букв с движением эта кнопка проверяет только форму и не завершает букву.

## Ограничения точности

На отложенном последовательном блоке примеров точность основной модели формы составила **90,1%**. Для И, Л, М и Ш/Щ полнота была заметно ниже; после этой оценки итоговая модель дообучена на всех опубликованных примерах, поэтому цифра относится к проверке до дообучения. Дополнительная модель А на отдельном блочном тесте приняла **188 из 188** примеров А и **0 из 6162** других форм. Дополнительная модель Ш/Щ приняла **223 из 225** примеров формы Ш/Щ и ошибочно приняла **59 из 6125** других форм. Модель И приняла **225 из 225** примеров И и **0 из 6125** других форм. Модель К приняла **221 из 225** примеров К и **0 из 6125** других форм. Модель Д приняла **225 из 225** примеров Д и ошибочно приняла **39 из 6125** других форм. Пороги выбраны на проверочной части, а не на тестовой. Это записи того же датасета, а не независимые люди. Один снимок пользователя с буквой А и его зеркальная версия прошли проверку в браузере; живую камеру на разных пользователях и экспертную правильность жестов ещё нужно проверить. Движение проверяется простыми правилами по точкам руки; его точность на людях не измерена. Для Й используется форма И, потому что README датасета отмечает ошибочные скелеты класса Й. Для З и Ц пока проверяется только статичная форма, хотя полный жест включает движение.

## Запуск

В Windows можно дважды щёлкнуть `START_WINDOWS.cmd` и открыть `http://localhost:8765/`. Окно сервера нужно оставить открытым. Скрипт использует Python из Codex, если он есть, либо установленный Python 3.

Это запуск только на своём компьютере. Для проверки жюри опубликуйте проект по инструкции ниже.

Для ручного запуска в папке проекта:

```powershell
python -m http.server 8765
```

Откройте `http://localhost:8765`. Для первой загрузки TensorFlow.js и MediaPipe нужен интернет. Камера работает на `localhost` или HTTPS.

## Обучение заново

Для обучения нужны `numpy` и текстовые файлы датасета; изображения JPG скачивать не нужно. Из папки проекта:

```powershell
python -m pip install numpy
 git clone --depth 1 --filter=blob:none --sparse https://github.com/Blockbattle/RSL-Dataset.git data/RSL-Dataset
 git -C data/RSL-Dataset sparse-checkout set text
 python training/train.py
 python training/train_a_invariant.py
 python training/train_sh_invariant.py
 python training/train_i_invariant.py
 python training/train_k_invariant.py
 python training/train_d_invariant.py
 python training/build_references.py
```

На некоторых установках Git для Windows у команды `git clone` требуется `git -c http.sslBackend=openssl clone ...`. Папка `data/` исключена из Git. Скрипты обучения и файлы модели входят в проект.

## Загрузка кода на GitHub

Создайте пустой репозиторий на GitHub и в этой папке выполните:

```powershell
 git init
 git add .
 git commit -m "Add Russian fingerspelling trainer"
 git branch -M main
 git remote add origin https://github.com/USERNAME/REPOSITORY.git
 git push -u origin main
```

Замените `USERNAME/REPOSITORY` на адрес своего репозитория. Для загрузки потребуется вход в GitHub. Если репозиторий будет публичным, сначала проверьте права на изображения и датасет.

## Публичный запуск через GitHub Pages

1. Создайте на GitHub **публичный** пустой репозиторий. Не добавляйте при создании README или `.gitignore`: они уже есть в проекте.
2. Из папки проекта выполните команды раздела «Загрузка кода на GitHub», подставив адрес этого репозитория.
3. На GitHub откройте репозиторий → **Settings** → **Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main**, папку **/(root)** и нажмите **Save**.
4. Дождитесь публикации. Ссылка появится в разделе Pages и обычно имеет вид `https://USERNAME.github.io/REPOSITORY/`. Откройте её на телефоне или другом компьютере и проверьте камеру, распознавание и загрузку моделей.

GitHub Pages отдаёт сайт по HTTPS, которое требуется браузеру для доступа к камере вне `localhost`. При первой загрузке нужны интернет и доступ к CDN TensorFlow.js и MediaPipe. Отдельный Python-сервер для посетителей опубликованного сайта не нужен.

## Описание для заявки на хакатон

**Проект:** «Жесты» — тренажёр русского дактильного алфавита. **Направление:** обучение и доступность коммуникации. Пользователь выбирает одну из 33 букв, показывает жест в камеру и получает результат и подсказку. MediaPipe определяет 21 точку руки; обученные на RSL-Dataset модели проверяют форму кисти. Для Д, Ё, Й, К, Щ, Ъ и Ь дополнительно проверяется движение руки: круг, поворот кисти, движение вниз или наклон по глубине кадра в зависимости от буквы. Для З и Ц сейчас проверяется только форма. **Режим «ошибка»:** если нужная форма не подтверждена, сайт не засчитывает букву и показывает подсказку для выбранной буквы; для динамической буквы отдельно сообщает, что форма найдена, но требуется движение. Ограничения точности описаны выше.
